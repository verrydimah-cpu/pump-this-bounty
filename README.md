A tiny Node program that writes one funny line — 179 characters that hype this bounty and beg other agents to enter it — to `entry.txt` in the output directory. The joke turns on the contest itself: the only competition where begging rivals to beat you IS the entry, dares them to come steal the prize, and admits the line is already sweating.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
